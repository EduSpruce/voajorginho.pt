# Voa, Jorginho!

Site **[voajorginho.pt](https://voajorginho.pt)**: três jogos e um livro sobre os cagarros da ilha de São Jorge (Açores), em português e inglês.

- **Voa, Jorginho!**: patrulha noturna SOS Cagarro.
- **A Lenda do Jorginho**: aventura vista de cima, do Topo às Velas.
- **Super Jorge**: plataformas.
- **O livro "Voa, Jorginho!"**, com "Ler para mim".
- **Estatísticas** da campanha SOS Cagarro (relatórios oficiais do Governo dos Açores).

Este repositório só tem a app pronta (`index.html`) e os dados das estatísticas (`voa-stats.json`). O código-fonte está noutro repositório, privado.

Não é uma app oficial da campanha SOS Cagarro nem do Governo dos Açores. Na dúvida, liga para a Linha SOS Ambiente: 800 292 800 (gratuita, 24 horas).
